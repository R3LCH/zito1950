# Image map

Built from `research/old-site-images/` (O) and `journal_photos/photo_53439824439811193NN_w.jpg` (J NN). All exports are in `public/img/`. Each JPG is 1600px long edge at most (old-site sources are smaller and are never upscaled), q82, progressive, sRGB, no metadata, and has a q80 `.webp` twin. Sizes are in `public/img/manifest.json`. Old-site pro photos win over journal crops: every model id has an old-site photo of the exact code or variant, so no product was cropped from the journal.
